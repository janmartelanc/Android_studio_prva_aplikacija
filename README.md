# Prva aplikacija v android studiotu.

Aplikacija vključuje dva TextView-a, dva radiobutton-a, ki sta povezana z buttongroupom. Odspodaj je še checkbox ter dva gumba. Prvi gumb je normalen button drugi pa floating action button.
Prvi gumb ob kliku prikaže toast message floating action button pa prikaže en normalen snackbar ter en snackbar, ki je čim bolj podoben toastu.
